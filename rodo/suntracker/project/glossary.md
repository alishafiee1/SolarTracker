# واژه‌نامه

> هر واژه همان معنایی را دارد که اینجا نوشته شده؛ در سناریوها و spec همین واژه‌ها به کار می‌روند.

| واژه | معنی | در کد |
|---|---|---|
| تراکر تک‌محوره | سازه‌ای که پنل را حول یک محور افقی شمالی-جنوبی از شرق به غرب می‌چرخاند | — |
| جک | عملگر ۲۲۰ ولتی که پنل را می‌چرخاند؛ دو جک موازی، با لیمیت‌سوئیچ داخلی | `Actuator` |
| زاویه چرخش (R) | زاویه پنل نسبت به افق؛ مثبت یعنی رو به غرب، صفر یعنی افقی | `rotationDeg` |
| زاویه هدف | زاویه‌ای که پنل باید داشته باشد، از روی موقعیت خورشید و محدود به حداقل و حداکثر | `targetDeg` |
| حد آستانه حرکت | کمترین اختلاف زاویه فعلی و هدف که حرکت را شروع می‌کند (پیش‌فرض ۵ درجه) | `moveThresholdDeg` |
| حالت ایمن | پنل افقی (صفر درجه)؛ در باد شدید و شب | `kStowDeg` |
| حالت اتوماتیک | پنل خودش دنبال خورشید می‌رود | `Mode::Auto` |
| حالت دستی | کاربر از پنل وب پنل را به شرق یا غرب می‌برد | `Mode::Manual` |
| حالت خطا | حرکت خودکار متوقف است تا کاربر خطا را ریست کند | `State::Fault` |
| قفل جهت | سیم‌کشی «رله ۱ روشن/خاموش + رله ۲ جهت» که برق را هرگز هم‌زمان به هر دو جهت نمی‌دهد | `MotionController` |
| تأخیر ایمن | مکث‌های اجباری بین توقف، تعویض جهت و حرکت بعدی | `SafetyTiming` |
| گیرکردن بازو | زاویه بعد از فرمان حرکت عوض نمی‌شود (و جریان بالاست) | `Fault::Stall` |
| کالیبراسیون دو مرحله‌ای | ثبت بردار گرانش یک بار در حالت افقی و یک بار کمی رو به شرق، برای پیدا کردن صفحه و جهت چرخش | `AngleCalibration` |
| هات‌اسپات | شبکه WiFi خود ESP32 با رمز اختصاصی، روی 192.168.4.1 | `WiFi AP` |
| رمز تنظیمات | رمز جدا از رمز هات‌اسپات، برای حرکت دستی و تغییر تنظیمات | `settingsPassword` |
| لاگ رویداد | فهرست چرخشی خطاها، حرکت‌ها و تغییر حالت با زمان، روی فلش | `EventLog` |
| ترانس جریان | سنسور SCT-013 دور سیم مشترک جک‌ها؛ جریان را بدون تماس می‌خواند | `ICurrentSensor` |
| شبیه‌ساز | مدل نرم‌افزاری جک، باد و سنسورها که منطق را بدون سخت‌افزار تست می‌کند | `lib/sim` |
| به‌روزرسانی آفلاین | نصب فایل .bin جدید از گوشی روی هات‌اسپات، با بازگشت خودکار در خرابی | `OtaUpdate` |
| ماژول اختیاری | بخشی از پروپوزال که کارفرما می‌تواند برای کم کردن هزینه حذف کند (ب۲/ج۲، ج۴، ج۵، ج۶)؛ در این پروژه کارفرما همه را خواسته است | — |
