# سند فنی: فونت داخلی و آسمان شب

**R1.** فونت `Vazirmatn-FD-NL` (Regular, SemiBold, Bold؛ فارسی، ارقام فارسی‌شکل، بدون لاتین) از نسخهٔ ۳۳٫۰۰۳ پروژهٔ وزیرمتن (لایسنس SIL OFL، متن در `docs/licenses/Vazirmatn-OFL.txt`) در `web/` است و با `embed_web.py` داخل بایناری می‌رود (جمع پنل حدود ۹۳ کیلوبایت، سقف ۱۵۰).
**R2.** فونت‌ها با `Cache-Control: max-age=1y, immutable` سرو می‌شوند. نام خانوادهٔ CSS برابر `VazirPanel` است تا با فونت نصب‌شده روی دستگاه قاطی نشود؛ حروف لاتین به Tahoma یا Segoe UI برمی‌گردند.
**R3.** آسمان شب (ارتفاع خورشید زیر ‎−۴°): ماه هلالی بالا-راست (سمت شرق)، چهار ستارهٔ کوچک کنار آن و هیچ ستاره‌ای نزدیک نوشته‌ها.
**R4.** ماه ۱٫۵ ثانیه بعد شروع به طلوع از افق می‌کند و ۵ ثانیه طول می‌کشد؛ ستاره‌ها بعد از آن ظاهر می‌شوند و با تأخیرهای متفاوت چشمک می‌زنند؛ هالهٔ ماه آرام نفس می‌کشد.
**R5.** با `prefers-reduced-motion` همه‌چیز بی‌حرکت و ثابت نمایش داده می‌شود.
**R6.** انیمیشن فقط CSS است؛ ESP32 فقط فایل‌های ثابت را یک بار می‌فرستد.

## Decisions

- ارقام لاتین (آی‌پی، شمارهٔ نسخه) با همین فونت شکل فارسی می‌گیرند ولی کد حروفشان لاتین می‌ماند و کپی می‌شوند (default, not asked). Because ظاهر یک‌دست می‌شود.
