# سند فنی: آیکون باتری در هدر

**R1.** `GET /api/status` فیلد `mainsV` (ولت، یک رقم اعشار، هموارشده) را هم می‌دهد؛ بدون اندازه‌گیری null است.
**R2.** هدر: آیکون باتری با درصد داخل (فقط وقتی باتری اندازه‌گیری شود) و آیکون برق شهر با ولتاژ (فقط وقتی پایهٔ شارژر وصل است). رنگ باتری: سبز، زرد برای `low`، قرمز برای `critical`.
**R3.** با قطع برق شهر آیکون خط می‌خورد، قرمز می‌شود و به‌جای ولتاژ «قطع» نوشته می‌شود.
**R4.** کاشی باتری داشبورد برداشته شد؛ ولتاژ دقیق باتری در راهنمای آیکون (title) است.
**R5.** متن‌های انگلیسی وضعیت (`Night`…) و واحد `km/h` فارسی شدند و ارقام سنسور زنده فارسی نمایش داده می‌شوند.

## Decisions

- فونت داخل پنل جاسازی نشد (default, not asked). Because دانلود فایل فونت و کتابخانهٔ برش آن نیاز به اجازه دارد؛ پیشنهاد جداگانه داده شد.
