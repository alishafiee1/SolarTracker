# کنسول USB کامل

با کابل USB می‌شود وضعیت کامل دستگاه را به‌صورت یک خط JSON خواند (`json`)، یک خودآزمایی گرفت (`selftest`) و لاگ را دید. برای آزمایش روی میز، حالت `raw` رله‌ها را مستقیم و بدون قفل‌های ایمنی به کامپیوتر می‌دهد؛ بعد از چند ثانیه بی‌خبری خودش خاموش می‌شود. علت خطای سنسور زاویه هم حالا در لاگ نوشته می‌شود.
